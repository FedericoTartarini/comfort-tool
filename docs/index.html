CBE Thermal Comfort Tool

Model explanations, a glossary and answers to common thermal-comfort questions.

The rewrite/v1 guide covers the four models below. It focuses on concepts, model inputs and outputs, and the standards or publications behind each method.

ModelWhat the page explains
PMV (ISO 7730)Predicted mean vote and predicted percentage dissatisfied using the ISO method.
PMV (ASHRAE 55)PMV and PPD using the ASHRAE method, including air-speed treatment.
Adaptive (ASHRAE 55)Comfort in eligible occupant-controlled naturally conditioned spaces.
Heat Index (Rothfusz)Apparent temperature from air temperature and humidity.

Documentation labels

rewrite/v1 identifies the revised model and reference pages. Archived identifies earlier interface or model documentation. These labels describe this guide’s scope; they do not assert that a later application commit has exactly the same feature set.

# CBE Thermal Comfort Tool: user guide

## Export image

Export image, beside the chart's controls, writes the chart as a file in two formats, PNG and SVG, and no others.
Each comes in two sizes, a single column 90 mm wide and a double column 190 mm wide, with its lettering at 8 pt, so
a file placed at its width needs no scaling. A PNG is drawn at 600 dpi; where a journal asks 1000 or 1200 dpi for
line art, use the SVG. A journal that asks for EPS or PDF takes neither: convert the SVG once, in a vector editor
such as Inkscape or Illustrator. The SVG names Arial for its lettering and does not embed it, so the machine that
opens or converts it draws the text in its own Arial, or in Helvetica or a sans-serif where Arial is missing.

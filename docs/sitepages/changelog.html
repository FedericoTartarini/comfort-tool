Changelog

What changed, and what it means for a calculation you ran before.

Maintainers: dated release entries have not been added to this page yet. The section below records the change from the previous tool, which is what users will notice first; per-release entries should be appended above it as releases are published. Until then this page deliberately claims no version numbers or dates rather than inventing them.

This version, compared with the previous tool

This is a rebuild rather than an update. If you are returning from the earlier tool, these are the differences that change an answer or move a control.

Changes that can alter a result

ChangeWhat to do about it
PMV is now two separate models. ASHRAE 55 and ISO 7730 are distinct, with different calculations, different input limits and their own workspaces. They are not interchangeable. Check which one an old result used before comparing. See Thermal comfort questions for how they differ.
Dynamic clothing is no longer automatic. The previous tool applied the movement correction in the background. It is now an input modifier you switch on. Enable it to reproduce an older result that relied on it.
Solar gain is now a modifier, not a separate feature. It applies to the two PMV models and adds to mean radiant temperature as before. Nothing, beyond knowing where it moved to.

New in this version

  • Time-series heat-strain exposure built from a sequence of segments, simulated off the main thread. Currently PHS only.
  • Explore any model, selectable chart axes, multiple outputs and editable comfort bands. Band edits are presentational and do not change the calculation.
  • An ISO 7730 workspace, with its own PMV variant.
  • ISO 7933:2023 as a first-class workspace. PHS was previously a side feature.
  • Four outdoor and weather indices UTCI, Heat Index, Humidex and Wind Chill available in Explore.
  • Five humidity input modes and an air / operative temperature mode, on every workspace.
  • Compare mode with up to three input sets, per-input visibility and a chart baseline picker.
  • Chart export to PNG and SVG, per-chart axis selection and a zone toggle.
  • Share links that encode the whole calculation in the URL, with nothing uploaded.

Interface

  • The three-panel single-page layout is gone. The tool is now six workspaces reached from a sidebar, with readable URLs that can address an exact model.
  • Charts are declared per model, generally one or two each, rather than a fixed set of five shared across the tool.
  • Share is the only header action. The previous tool's Reset, Save and Reload buttons are not present in this build.

Not present in this version

These appeared in the previous tool and are not in this build. Whether any will return has not been decided, so they are recorded here rather than quietly dropped.
FeatureNearest equivalent now
File uploadNone. Inputs are entered by hand.
Fans during heatwavesNone. The air-speed control option on PMV (ASHRAE 55) is a different thing it applies the standard's air-speed limits, it does not model a fan during a heat event.
Globe temperature calculatorNone. Enter mean radiant temperature directly.
Set pressureNone.
Local thermal discomfortNone.
Sharing on Time-seriesNot offered by design a link cannot represent a multi-segment scenario. Export the charts instead.

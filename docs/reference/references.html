Reference

References and citations

Every number this tool produces comes from a published model. This page lists the source for each one, and marks the few places where a value shown in the interface has no published source behind it.

The list replaces the earlier ashrae55-references page, which covered a single standard. The tool now implements nine models drawn from four standards and five independent publications, so the citations are grouped by what they support rather than by standard.

How to cite the tool

If you use the CBE Thermal Comfort Tool in published work, cite the software paper:

Tartarini, F., Schiavon, S., Cheung, T., Hoyt, T., 2020. CBE Thermal Comfort Tool: online tool for thermal comfort calculations and visualizations. SoftwareX 12, 100563. https://doi.org/10.1016/j.softx.2020.100563

Cite the tool in addition to, not instead of, the standard or publication defining the model you used. A reader needs both: the model to know what was calculated, and the tool to know what implemented it.

Standards

RefStandardUsed by
S1 ANSI/ASHRAE Standard 55, Thermal Environmental Conditions for Human Occupancy. PMV (ASHRAE 55), Adaptive (ASHRAE 55), and the morning clothing estimate modifier
S2 ISO 7730:2005, Ergonomics of the thermal environment Analytical determination and interpretation of thermal comfort using calculation of the PMV and PPD indices and local thermal comfort criteria. PMV (ISO 7730)
S3 EN 16798-1:2019, Energy performance of buildings Ventilation for buildings Indoor environmental input parameters for design and assessment of energy performance of buildings addressing indoor air quality, thermal environment, lighting and acoustics. Adaptive (EN 16798-1)
S4 ISO 7933:2023, Ergonomics of the thermal environment Analytical determination and interpretation of heat stress using calculation of the predicted heat strain. PHS, on both the ISO 7933 and Time-series workspaces
S5 ISO 9920:2007, Ergonomics of the thermal environment Estimation of thermal insulation and water vapour resistance of a clothing ensemble. The dynamic clothing modifier
ISO 7730 edition. The tool implements the applicability limits of ISO 7730:2005. A later edition of the standard has since been published. The PMV equation itself is unchanged, but do not read a result from this tool as a conformity statement against an edition it does not implement. The PMV (ISO 7730) page states the limits the tool actually applies.

Calculation engine

No model is implemented twice. Every value in the tool is computed by jsthermalcomfort, a JavaScript port of the pythermalcomfort library maintained by the Center for the Built Environment. The tool vendors it as a pinned dependency, so a given release of the tool always calculates through a known version of the engine.

  • jsthermalcomfort github.com/CenterForTheBuiltEnvironment/comfort.js
  • Per-function documentation for the engine is published with this site under API Reference.

If a number here disagrees with one from another implementation of the same model, the engine is the place to look first. The tool selects inputs and presents results; it does not contain its own copy of the equations.

Values with no published source

Most band boundaries in the tool come from the standard or paper that defines the model, and the model page cites it. A few do not. They are listed here rather than left to look authoritative.

WhereWhat is tool-specificWhat this means when you report it
PMV, both variants The half-step boundaries that map a PMV value to the seven thermal-sensation labels (−2.5, −1.5, −0.5, +0.5, +1.5, +2.5). The ±0.5 acceptability range is from the standards. The remaining midpoints are a presentation convention for labelling the scale, not a criterion to cite.
Humidex The category boundaries at 35 and 54, and several of the category labels. Environment and Climate Change Canada publishes a coarser set of ranges. Report the Humidex value, not this tool's label, if the label has to be defensible.
Wind Chill The labels “30 minutes”, “10 minutes” and “2 minutes to frostbite” at 1400, 1600 and 2300 W/m². The underlying W/m² cooling-power scale has historical support; these exposure-time labels at these boundaries could not be traced to it. Treat them as indicative.
Heat Index The Celsius category boundaries (27, 32, 39, 51 °C). These are rounded conversions of the U.S. National Weather Service categories, which are defined in Fahrenheit. Expect a degree of disagreement at a boundary.
This list is deliberately visible rather than buried. A band boundary presented without a source is the kind of number that ends up quoted in a report as though a standard defined it. If you find a traceable source for any of the above, it belongs on the model page and here.

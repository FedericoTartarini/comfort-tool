Models

PMV / PPD · ISO 7730

Estimates group thermal sensation and the percentage dissatisfied using the ISO PMV method.

Standard: ISO 7730.

Source: pythermalcomfort — Model definition and parameter documentation. See also References.

What it computes

PMV describes a group’s average sensation; PPD estimates the proportion dissatisfied. These are group predictions, not a guarantee for an individual.

The ISO implementation follows the Fanger PMV formulation. Select the standard edition required by your assessment; the current upstream documentation supports the 2005 and 2025 editions. The edition used by a particular app release must be checked rather than inferred from an upstream default.

Inputs

The six main inputs are listed below in SI display units. Library calls also provide an external-work parameter; the values exposed by an application should be checked against its release.

InputUnitMeaning
Air temperature°CTemperature of the air around the occupant.
Mean radiant temperature°CRadiant environment surrounding the occupant.
Relative air speedm/sAir speed relative to the body, including activity effects where the method requires them.
Relative humidity%Moisture level expressed relative to saturation.
Metabolic ratemetActivity-related metabolic heat production.
Clothing insulationcloInsulation of the clothing ensemble, with method-specific adjustment where required.

Source: pythermalcomfort — input parameters. See also References.

Outputs

OutputMeaning
PMVThermal sensation on the −3 (cold) to +3 (hot) scale.
PPD (%)Predicted percentage dissatisfied. A lower value indicates fewer dissatisfied occupants.
Thermal sensation categoryThe category associated with the PMV value in the upstream model output.

Source: outputs: PMV, PPD and returned classification fields.

Applicability and interpretation

Check applicability separately from comfort. An applicable result can still describe uncomfortable conditions. A chart viewport is not an applicability limit, and a coloured sensation band is not, by itself, a compliance verdict.

Use the linked model documentation and the required standard edition for numerical limits. Input-control and chart ranges do not replace the method’s applicability requirements.

Source: pythermalcomfort — applicability and model notes. See also References.

Source: model applicability and interpretation.

Using the result

Report the model, standard edition, input assumptions, PMV and PPD. State any applicability limitation. Do not describe a PMV-only calculation as a complete assessment of every provision of the standard.

Source: model outputs.
